## 成本说明

本项目使用阿里云按量付费资源，整体成本控制在每月 50 元以内：

| 资源 | 用量 | 费用（按量付费） |
|------|------|------------------|
| OSS 存储 | 约 5GB 样本数据 | 新用户有 90 天体验版本，资源按量付费，约 0.3 元 |
| MaxCompute 计算 | 约 1 亿行数据处理 | 约 1.5-3 元（一次性） |
| DataWorks | 基础版按量 | 约 3–5 元 |
| Quick BI | 个人版 | 免费 |
| **合计** | | **50 元以内** |

**成本控制措施**：
- 数据抽样至 500 万条，减少计算量
- MaxCompute 表设置 LIFECYCLE 自动清理
- 任务完成后暂停调度，避免空跑
- 设置预算告警，防止意外费用
