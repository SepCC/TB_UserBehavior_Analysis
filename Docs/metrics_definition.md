# 核心指标口径定义

本文档定义电商用户行为分析项目中所有核心指标的业务含义、计算口径和数据来源，确保指标可追溯、可复现，并统一团队理解。

## 一、通用约定

| 项目 | 说明 |
| :-- | :-- |
| 日期格式 | 统一为 yyyy-MM-dd，字符串类型 |
| 分区字段 | dt ，STRING 类型，按天分区 |
| 活跃定义 | 用户当天发生任意行为(pv、fav、cart、buy)即视为活跃 |
| 去重口径 | 所有"用户数"指标均使用 COUNT(DISTINCT user_id) |
| 行为类型 | pv：浏览; fav：收藏; cart：加购; buy：购买 |
| 数据来源表 | dwd_user_behavior_detail(DWD 明细表) |

## 二、流量指标

| 指标名称 | 英文/缩写 | 业务释义 | 计算口径 | 数据来源 | 备注 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 浏览量 | PV | 页面浏览次数 | COUNT(*) WHERE behavior_type='pv' | dwd_user_behavior_detail | 每次浏览计 1 次，同用户多次浏览累加 |
| 独立访客数 | UV | 去重后的活跃用户数 | COUNT(DISTINCT user_id) (所有行为) | 同上 | 一天内多次访问只计 1 个 UV |
| 人均访问页面数 | Visit_Depth | 平均每个用户浏览的页面数 | PV / UV | 同上 | 分母为 UV，需处理除零 |
| 跳出率 | Bounce_Rate | 仅浏览一个页面即离开的用户占比 | 仅发生 1 次 pv 的用户数 / 有 pv 行为的用户数 | 同上 | 因无会话 ID，采用近似口径：当日 pv_cnt=1 的用户视为跳出 |

**跳出率近似说明**：

严格跳出应指"只浏览一个页面且无收藏/加购/购买等深度行为"。本项目无会话数据，故简化为"当日仅 1 次 pv 行为"的用户占比，并在文档中注明。

## 三、转化漏斗指标

漏斗阶段：浏览 → 收藏/加购 → 购买

| 指标名称 | 业务释义 | 计算口径 | 数据来源 | 备注 |
| :--- | :--- | :--- | :--- | :--- |
| 浏览用户数 | 发生过浏览行为的去重用户数 | COUNT(DISTINCT user_id) WHERE behavior_type='pv' | dwd_user_behavior_detail | 漏斗第一步 |
| 收藏/加购用户数 | 浏览用户中，发生过收藏或加购行为的去重用户数 | COUNT(DISTINCT user_id) WHERE behavior_type IN ('fav', 'cart') 且限定为浏览用户集合 | 同上 | 漏斗第二步，需要整整用户来自第一步 |
| 购买用户数 | 收藏/加购用户中，发生过购买行为的去重用户数 | COUNT(DISTINCT user_id) WHERE behavior_type = 'buy' 且限定为第二步用户集合 | 同上 | 漏斗第三步 |
| 浏览→收藏/加购转换率 | 第二步用户数 / 第一步用户数 | fav_cart_uv / pv_uv | 同上 | 百分比，保留两位小数 |
| 收藏/加购→购买转化率 | 第三步用户数 / 第二步用户数 | buy_uv / fav_cart_uv | 同上 | 百分比 |
| 整体转化率 | 第三步用户数 / 第一步用户数 | buy_uv / pv_uv | 同上 | 百分比 |

**漏斗计算注意**：

每一步的用户集合必须包含于上一步的用户集合中，即第二步用户必须发生过浏览，第三步用户必须发生过收藏/加购。实现时可以通过逐步 JOIN 或条件累加保证。

## 四、用户留存指标

| 指标名称 | 业务释义 | 计算口径 | 数据来源 | 备注 |
| :--- | :--- | :--- | :--- | :--- |
| 次日留存率 | 基准日活跃用户中，次日仍活跃的用户占比 | 基准日次日活跃用户数 / 基准日活跃用户数 | dwd_user_behavior_datail | 只需基准日和次日两个点活跃，不要求连续 |
| 3 日留存率 | 基准日活跃用户中，第 3 天仍活跃的用户占比 | 基准日后第 3 天活跃用户数 / 基准日活跃用户数 | 同上 | 同上 |
| 7 日留存率 | 基准日用户中，第7天仍活跃的用户占比 | 基准日后第 7 天活跃用户数 / 基准日活跃用户数 | 同上 | 同上 |

**留存口径说明**：

- 基准日：通常为自然日，计算该日活跃用户在后续第 n 天的留存情况。
- 活跃定义：当天发生任意行为即视为活跃。
- 不要求中间日期连续活跃，秩序基准日和第 n 天两个点活跃。

## 五、复购率

| 指标名称 | 业务释义 | 计算口径 | 数据来源 | 备注 |
| :--- | :--- | :--- | :--- | :--- |
| 复购率 | 统计周期内购买次数 ≥ 2 的用户占比 | 购买次数 >= 2 的用户数 / 有购买行为的用户数 | dwd_user_behavior_detail | 统计周期为最近 30 天滚动窗口 |

**滚动 30 天说明**：

以每个观察日期为终点，向前推 29 天(共 30 天)作为统计窗口，计算该窗口内用户的购买次数。和购买次数按 behavior_type = 'buy' 的记录数累加。

## 六、RFM 用户分层

| 维度 | 业务释义 | 计算口径 | 数据来源 | 备注 |
| :--- | :--- | :--- | :--- | :--- |
| R(Recency) | 最近一次购买距统计日的天数 | DATEDIFF(统计日, MAX(购买日期), 'dd') | dwd_user_behavior_detail | 值越小代表越活跃 |
| F(Frequency) | 统计周期内累计购买次数 | COOUNT(*) WHERE behavior_type = 'buy' | 同上 | 历史累计 |
| M(Monetary) | 消费金额 | 本项目无金额字段，用 F 近似代替 | —— | —— |

**分层规则**：

| 分层标签 | 条件 |
| :--- | :--- |
| 重要价值客户 | R ≤ 30 且 F ≥ 5 |
| 重要发展客户 | R ≤ 30 且 F < 5 |
| 重要保持客户 | R > 30 且 F ≥ 5 |
| 一般客户 | R > 30 且 F < 5 |

**说明**：

- 统计日为数据集中最新日期或调度参数指定的日期。
- 仅分析有购买行为的用户，从未购买的用户不纳入 RFM 分层。
- 该表按日分区存储快照，用户分层会随时间变化。

## 七、商品分析指标

| 指标名称 | 业务释义 | 计算口径 | 数据来源 | 备注 |
| :--- | :--- | :--- | :--- | :--- |
| 热销类目 TOP N | 按购买次数排名最高的商品类目 | 按 category_id 聚合 COUNT(*)，降序取前 N | dwd_user_behavior_detail | 可同时统计购买用户数 |
| 热销商品 TOP N | 按购买次数排名最高的商品 | 按 item_id 聚合 COUNT(*)，降序取前 N | 同上 | 同上 |
| 关联购买支持度 | 同时购买商品 A 和 B 的用户占比 | 同时购买 A 和 B 的用户数 / 总购买用户数 | 同上 | 需基于用户购买商品集合计算 |
| 关联购买置信度 | 购买 A 的用户中同时购买 B 的比例 | 同时购买 A 和 B 的用户数 / 购买 A 的用户数 | 同上 | —— |
| 关联购买提升度 | 购买 A 对购买 B 的提升程度 | 置信度 / (购买 B 的用户数 / 总购买用户数) | 同上 | 大于 1 表示正相关 |

**关联购买计算说明**：

由于计算量较大，建议先对热销商品做 TOP 筛选，再计算两两商品的共现关系。
